💡 Reference Implementation & Testing Harness for libinfer
This application is an example demonstration created to test, validate, and showcase the capabilities of infer_core.cpp from the libinfer repository.
📌 Note on Stability: infer_core.cpp is production-hardened, thread-safe, and fully isolated. Any bugs, UI glitches, or formatting quirks present in this desktop sample reside strictly within the demo wrapper application (AppUI, AIEngine, or GUI rendering layer)—not in infer_core.cpp.

✨ Features
⚡ Zero-Latency Local Inference: Powered by GGML / llama.cpp backends via the lightweight libinfer C API wrapper.
💬 Streaming Output: Token-by-token real-time translation with live word/character statistics and stop/cancel support.
🔤 Orthography & Grammar Correction: Automatically detects when input and output languages match and switches mode to grammar and style refinement.
🧹 Reasoning Tag Neutralization: Automatic filtering of <think>...</think> internal reasoning blocks generated by DeepSeek / Qwen 3 models.
📥 Integrated Model Downloader: Asynchronous background download manager powered by libcurl for automatic GGUF model fetching.
📑 Document Parser: Native support for loading text files (.txt, .md, .csv, .json, .log) with extensible hooks for PDF and DOCX parsing.
🎨 Multilingual UI: SDL3 + OpenGL 3 + Dear ImGui frontend with full CJK, Cyrillic, Arabic, Hebrew, Devanagari, and Thai font rendering.
🤖 Supported Models
The built-in model downloader supports three pre-configured, high-accuracy GGUF presets:
Model	Quantization	Size	Supported Languages & Features
Qwen 3 8B	Q4_K_M	~5.20 GB	Next-gen architecture with native support for 119 languages.
Qwen 2.5 7B Instruct	Q4_K_M	~4.68 GB	Exceptional accuracy across 29 core languages.
Llama 3.2 3B Instruct	Q8_0	~3.42 GB	Lightweight & high speed (French, English, German, Italian, Spanish, etc.).

🚀 How to Use
Launch the Application: Run the compiled binary (Home Translator or local_translator).
Download or Select a Model:
On first launch, the AI Models Download Menu modal will open automatically if no models are detected.
Click Download Now on any preset (e.g., Qwen 3 8B) to download directly into the ./models directory.
Configure Options:
Choose your Input Source (Window Text, Clipboard, or Loaded File).
Select the Source Language and Target Language.
Translate / Correct:
Click TRANSLATE to trigger real-time asynchronous streaming generation.
Click CANCEL / STOP at any point to stop token generation cleanly without freezing the UI.
💻 Integration Example (infer_core.cpp)
Below is a minimal snippet demonstrating how cleanly ai_engine.cpp integrates with infer_core.cpp:
code
C++
#include "infer.h"

// 1. Initialize Context
infer_ctx* ctx = infer_init();

// 2. Load Model GGUF File
if (infer_load_model(ctx, "models/Qwen3-8B-Q4_K_M.gguf", 4096)) {
    
    // 3. Set Up Chat Messages
    infer_chat_msg msgs[2];
    msgs[0] = { "system", "You are an expert translator from English to French." };
    msgs[1] = { "user", "Hello world! Local AI inference is fast and private." };

    // 4. Stream Async Generation with Callback
    infer_generate_chat_async(
        ctx, 
        msgs, 
        2, 
        /* max_tokens */ 512, 
        [](const char* piece, void* user_data) -> bool {
            std::cout << piece << std::flush;
            return true; // Return false to abort streaming early
        }, 
        nullptr
    );

    // 5. Wait for Generation to Complete & Cleanup
    infer_wait(ctx);
    infer_free(ctx);
}
